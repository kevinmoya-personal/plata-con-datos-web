Política de privacidad

Última actualización: 26 de octubre de 2026

Qué es esta aplicación

"Publicador Pimenton" es una herramienta interna que usa el propio titular del canal de YouTube Pimentón y Algodón para publicar automáticamente los episodios y Shorts de su serie animada infantil en su propio canal.

Datos de Google a los que accede

La aplicación solicita acceso únicamente a la cuenta de YouTube del titular del canal, con el permiso necesario para subir videos y miniaturas (alcance youtube.upload). No accede a datos de otras personas.

Cómo se usan y guardan

  • El token de acceso se guarda cifrado como secreto del repositorio privado del titular en GitHub y solo se usa para publicar los videos del canal.
  • No se venden, transfieren ni comparten datos con terceros.
  • No se usan datos de Google para publicidad ni para entrenar modelos de inteligencia artificial.

El uso de la información recibida de las APIs de Google cumple la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
